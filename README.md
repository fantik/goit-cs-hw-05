# Домашнє завдання: асинхронна обробка

## Завдання 1. Сортування файлів

Скрипт читає теку, яку ви йому дасте, і всі теки всередині неї. Кожен файл копіюється в теку результату. Розширення стає назвою підтеки: усі `.txt` потрапляють у `txt`, усі `.jpg` у `jpg`. Файл без розширення йде в `other`.

`JPG` і `jpg` для скрипта одне й те саме, тому вони лежать разом.

Читання і копіювання асинхронні. Якщо якийсь файл або теку не відкрились, помилка пишеться в консоль, а решта файлів обробляється далі.

У конспекті шляхи роблять через aiopath. На Python 3.14 ця бібліотека навіть не імпортується, тому тут стоїть anyio. Тека все одно читається асинхронно, файл копіюється через aioshutil, як у прикладі з лекції.

Готова тека з файлами вже лежить у `task1/source`. Там є `.txt`, `.jpg`, `.png`, `.csv`, `.md`, вкладені теки і один файл без розширення.

```bash
cd task1
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py source dist
```

`source` - звідки читати. `dist` скрипт створить сам і покладе туди копії. Якщо другий аргумент не передати, тека теж називатиметься `dist`.

Можна підставити будь-яку свою теку замість `source`.

Теку результату скрипт не читає ще раз. Інакше він почав би копіювати вже розкладені файли.

Якщо в різних місцях лежать два файли з однаковою назвою і однаковим розширенням, у результаті лишається один. Це той, який скопіювався останнім.

## Завдання 2. Частота слів

Скрипт завантажує текст за посиланням, рахує слова через MapReduce і малює 10 найчастіших.

MapReduce такий, як у конспекті. Map і reduce ідуть у потоках. Shuffle лишається в одному місці, бо йому треба зібрати всі пари разом.

Крапки, коми і регістр прибираються. `Hello,` і `hello` - це одне слово.

```bash
cd task2
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Потрібен інтернет. Спочатку в консолі будуть 10 слів і скільки разів кожне зустрілось. Потім відкриється вікно з графіком. Закрийте його, і програма завершиться.

Посилання стоїть на початку `main.py`. Це Nineteen Eighty-Four з конспекту. Картинка в умові лише приклад, у цієї книги свої числа. Посилання можна замінити.
